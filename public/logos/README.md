# Product label logos

Place brand logo images here so the print label component can display them:

- **mipa.jpeg** – Mipa brand logo (used when formula subcategory has brand `mipa`)
- **rosner-logo.jpeg** – Rosner brand logo (used when formula subcategory has brand `rosner` or no match)

The SmallLabel component references these as `/logos/mipa.jpeg` and `/logos/rosner-logo.jpeg`. Add the actual image files to this folder.
